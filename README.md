# excellence

Knowledge repository of [Digital Humanities Craft](https://dhcraft.org). Under construction.

> [!WARNING]
> **Never enable GitHub Pages on this repository.** The live blog at
> https://dhcraft.org/excellence/ is served by the organization site
> (`digitalhumanitiescraft.github.io`). A project site named `excellence`
> would shadow that path and break the blog.

## History

Until July 2026 this repository carried the DHCraft blog, system prompts and
the early Promptotyping prototypes. That content moved during the dhcraft.org
migration:

- **Blog**: https://dhcraft.org/excellence/
- **Promptotyping method** (interactive paper, templates, glossary): https://dhcraft.org/Promptotyping/
- **Demos and promptotypes**: https://dhcraft.org/demos/ ([source](https://github.com/DigitalHumanitiesCraft/demos))
- **Method paper**: Pollin 2026, [L.I.S.A. Wissenschaftsportal](https://lisa.gerda-henkel-stiftung.de/digitale_geschichte_pollin), archived with DOI [10.5281/zenodo.14160875](https://doi.org/10.5281/zenodo.14160875)

The full pre-2026 state of this repository remains archived in
[Zenodo v1.0.0](https://doi.org/10.5281/zenodo.14160876) and in
[Software Heritage](https://archive.softwareheritage.org/swh:1:dir:87dbf7a31299dc8751563ed14359c3663319c312).
The git history was restarted in July 2026; the old history exists as a local
mirror bundle.

The directory `promptotyping/szd-annotation-timeline/` is kept as a stub
because published literature links to it.
